# Architecture

Technical system designs and finalized architectural decisions belong here.

## Lifecycle

1. New system designs and review briefs live in [`proposals/`](proposals/).
2. External feedback is incorporated into the proposal.
3. Final choices are recorded as focused ADRs in [`decisions/`](decisions/).
4. Coding begins only after the relevant proposal and decisions are approved.
